# DiceScribe - a TTRPG Note Manager

DiceScribe is a customizable TTRPG note manager built with Python that includes character sheet templates, folder management, a Roll Wizard to make game action quicker, and more. 

## Features

### Organization

- **Categorization**: Create and organize folders by campaigns, with customizable categories (e.g., NPCs, quests, player info).
- **Quick Switch**: A fast toggle between notes, character sheets, and other pages.

### Search and Navigation

- **Directory**: Users can quickly get to important scenes or notes when needed.
- **Search Bar**: Search through all notes and folders to find key moments or details.

### Templates

- **Character Sheet Templates**: Pre-made templates for character details, with options for further customization.

### Additional Features

- **Roll Wizard**: A wizard designed to help make game actions quicker.

## Getting Started

> DiceScribe will currently only run on Windows 11 or higher.

### From Release

1. **Download the Latest Release**:
   - Navigate to the [Releases](https://github.com/apendarvis/DiceScribe/releases) page on the GitHub repository.

2. **Extract Files**:
   - After downloading the '.zip' file, extract it to the directory of your choice.

3. **Run the Application**:
   - Locate the extracted folder and double-click on the '.exe' file to launch the application
